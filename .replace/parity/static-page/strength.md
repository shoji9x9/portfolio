### 上流摂動の解釈

現行は API を持たない静的サイトであり、**データの上流 = document 応答そのもの**。そのため
「document 応答の文字列置換」と「外部画像 GET の遮断」を上流摂動として使い、静的マークアップの
文言・構造は DOM 摂動（本スキルが第二経路として定める手段）で注入した。

## 差分器の健全性

- 既知の差を赤にできるか: **確認済み**。
  - 特性照合: F9（色）・F10（余白）・F11（相対幾何）で赤。
  - 画素: F9・F10・F11 に加え、DOM 摂動の F1・F2・F3・F5・F6・F12 でも赤。
  - aria 比較: 構造の DOM 摂動 F5・F7・F8、および文言・並び・href の F1・F2・F3・F4・F6 で赤。
- 注入量がノイズ基準値に埋もれないか: **埋もれない**。ノイズ基準値は全ビューポート・全状態で
  `pixel_diff = 0` / `trait_diffs = 0`（[`baseline/noise.json`](baseline/noise.json)）であり、
  注入時の差分はいずれも 1 件以上。**偽陽性の対照（注入なし）も 4 経路すべて緑**であり、
  「差分が出る＝注入によるもの」と言い切れる。
- parity-diff へ引き渡す差分器（ツール・しきい値・ノイズ基準値の記録先）: `metadata.json` の
  `differ` / `noise_baseline`

## 未検証の故障種別

カタログの外は射程外であり、以下の緑は「反例が見つからなかった」に過ぎない。**スイートが強いとは宣言しない。**

| 未検証の故障種別 | 理由 |
| --- | --- |
| DB 意味論の差（collation・NULL 順序・タイムゾーン） | 現行に DB が無く、導出元が存在しない |
| フォーム・ダイアログ・バリデーションの回帰 | 現行に該当 UI が無い（`gaps.md` 参照） |
| 権限・ロールによる表示差 | 現行は認証を持たない公開ページ |
| アニメーションの差 | 差分比較でアニメーションを停止させるため、この手法では原理的に扱えない（対象外） |
| hover / focus 状態の画素・特性ベースライン相手の照合 | ベースラインは既定状態で採取している。状態側の差分器照合は parity-diff で状態別ベースライン（`baseline/<viewport>/{hover,focus}/`）を使って行う |
| 外部画像バイナリ自体の変化 | 外部サービスの応答は可変。URL・alt・配置・描画可否のみを対象にする方針（strategy 準拠） |
| モバイル以外のブレークポイント | 現行 CSS に幅ベースのメディアクエリが 0 件のため、代表 2 種（desktop / mobile）で足りると判断した |
