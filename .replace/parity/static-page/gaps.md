## 特性化できなかった箇所と理由

| 箇所 | 種別 | 理由 | 対応 |
| --- | --- | --- | --- |
| フォームの初期値・バリデーション（文言・発火タイミング） | 現行に該当 UI 無し | 現行 `/` は読み取り専用の静的ページで、`<form>`・`<input>`・`<select>` を 1 つも持たない | 記録のみ（対象外） |
| ダイアログ・メニュー・セレクト・日付ピッカーの操作 | 現行に該当 UI 無し | 同上。操作アダプタで吸収すべき実装差が現時点で存在しない | 記録のみ（新側で導入されたら parity-replace で操作アダプタを足す） |
| 検索・フィルター・ソート・ページネーション | 現行に該当 UI 無し | 単一ページで一覧の絞り込み・改ページが無い | 記録のみ（対象外） |
| 空データ・エラー・トーストの状態表示 | 現行に該当 UI 無し | 静的データのため空・エラーの分岐が存在しない | 記録のみ（対象外） |
| ローディング表示 | 明示的な loading UI 無し | 現行にローディング indicator が無い（画像は通常の `<img>` 読み込み） | 記録のみ（対象外） |
| 権限・ロールによる表示差 | 認証が無い | `current-prod` は `auth` 未定義の公開ページで、ロールの概念が無い | 記録のみ（対象外） |
| 書き込み系（作成・更新・削除）の挙動 | 現行に該当機能無し・target の禁止事項 | 現行は静的サイトで書き込み経路が無い。加えて `current-prod` の `forbidden_actions` が書き込みを禁じている | 記録のみ（対象外） |
| linkpreview.net への LAPRAS プレビュー取得 | スコープ外の副作用 | `LINK_PREVIEW_API_KEY` を要するビルド時 `fetch`。現行を変更せずに同一リクエストを捕捉できない | 機能 `lapras`（Issue #23）の担当。本機能では扱わない |
| LAPRAS セクションの表示（プレビュー画像・タイトル） | 他機能の担当 | 同じページに同居するが機能 `lapras` の範囲。外部プレビュー画像は差し替わりうる | スクリーンショットではマスクし、`static-page` の assertion からは除外した |
| 外部バッジ画像のバイナリ | 外部サービスの応答が可変 | Shields.io・AtCoder の応答は時期・レーティングで変わる。正解として固定できない | URL・alt・配置・描画可否のみを検証対象にした（strategy 準拠）。AtCoder バッジはスクリーンショットでマスク |
| アニメーションのパリティ | 手法上の対象外 | 差分比較で `animations: "disabled"` により停止させるため、原理的に扱えない | 記録のみ（対象外） |

## 本スキルで採らなかった判断（意図的な非対象）

- **セクションを包む要素の role**: 現行は素の `div` で landmark を持たない。手書き aria
  スナップショットではセクション単位でアンカーし、包む要素の role を契約にしていない。新側が
  `<section>`＋見出し関連付け（`role=region`）へ改善しても赤くならない。
- **タブ順の停止数**: 到達可能性と相対順序だけを判定し、停止数の厳密一致は基準にしていない。
- **色値そのもの**: hover・dark の判定は「既定と変わること」までで、具体的な色値は契約にしていない
  （Tailwind v4 のパレット差を潰さないため）。色値の差は `parity-diff` の差分器が扱う。
- **プロフィール表を `<table>` で表すこと**: これは契約に**した**。表形式データの行・列関係を
  スクリーンリーダーで辿れることは提示方法の仕様であり、失うとアクセシビリティの退行になるため。
  新側で別構造にしたい場合は `component_diffs` での宣言が要る。
