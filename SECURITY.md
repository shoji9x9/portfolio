# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported while this project is
under active development.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting form for this repository:
<https://github.com/shoji9x9/portfolio/security/advisories/new>.

Do not disclose vulnerabilities in a public Issue. Reports are acknowledged
within 7 days. After a fix is available, the report and disclosure timeline are
coordinated with the reporter.
